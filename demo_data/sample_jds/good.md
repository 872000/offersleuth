# Junior Software Developer — Northwind Labs (Toronto, ON)

**Location:** Toronto, Ontario (hybrid, 2 days in office)
**Salary:** $65,000 - $80,000 CAD per year
**Type:** Full-time, permanent

## About the role

Northwind Labs builds logistics software used by warehouses across Canada.
We're hiring a Junior Software Developer to join our 6-person product team.
You'll pair with a senior engineer for your first three months and ship to
production in your first week.

## Responsibilities

- Build and maintain REST APIs with Java and Spring Boot
- Write React components for our internal dashboard
- Write unit tests with JUnit and participate in code reviews
- Take part in our on-call rotation (one week in six, compensated)

## Required

- 0-2 years of professional software development experience
- Java and Spring Boot
- Basic SQL (we use PostgreSQL)
- Git and GitHub workflow
- Clear written communication

## Nice to have

- React or another modern frontend framework
- Docker experience
- Familiarity with AWS

## Benefits

- Health and dental from day one
- 3 weeks vacation, plus a December shutdown
- $1,500 annual learning budget
- Defined working hours; we discourage after-hours messages
